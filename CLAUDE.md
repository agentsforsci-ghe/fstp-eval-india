# CLAUDE.md

This repository is the R data package `fstpindia`, built with washr, plus Quarto documents that analyse its data. All data come from one PDF: the 2023 Phase II report by the Centre for Science and Environment (CSE), *Evaluation of FSTPs and STP Co-treatment Systems across India* (`data-raw/1689832445895.pdf`, cited as `narain2023` in `analysis/references.bib`).

The GitHub repository is `agentsforsci-ghe/fstp-eval-india`. The package name differs from the repository name because R package names cannot contain dashes.

## Layout

- `data-raw/` holds the PDF, the extraction scripts, and hand-made inputs. It is build-ignored.
  - `00-helpers.R` holds the shared functions. Scripts `01` to `07` each build one dataset and must run in this order, because `07` reads the output of the others.
  - `plant-names.csv` is the hand-made lookup that gives each of the 73 plants one `plant_id` (e.g. `od-dhenkanal`). It records the name printed in each part of the report, because the spelling differs between tables (e.g. Shadnagar and Shandnagar).
  - `bod-discharge.csv` holds BOD values typed by hand from the PDF. It is the independent reference for checks and is copied to `tests/testthat/fixtures/bod-discharge-hand-typed.csv`.
  - `dictionary.csv` is the washr data dictionary. The descriptions are still empty. `codebook.csv` has the older descriptions for Table 9 and the BOD file.
- `data/*.rda` and `inst/extdata/*.csv` and `*.xlsx` are generated by the scripts. Do not edit them by hand.
- `analysis/` holds the Quarto documents and their rendered DOCX and HTML files. It is build-ignored.
- `prompts/` is the prompt archive written by the commit skill. `plans/` holds plans that are written to files.

## Commands

- Rebuild all data: `for s in data-raw/0[1-7]-*.R; do Rscript "$s"; done`. The scripts need `pdftotext` from poppler (`brew install poppler`). A rebuild from scratch must give byte-identical CSV files.
- Tests: `Rscript -e 'devtools::test()'`
- Check: `Rscript -e 'devtools::check()'`
- README: edit `README.Rmd`, then run `Rscript -e 'devtools::build_readme()'`. A git pre-commit hook rejects a commit where `README.md` is older than `README.Rmd`.
- Render the analysis documents: `quarto` is not on the PATH. Use `/Applications/RStudio.app/Contents/Resources/app/quarto/bin/quarto render` from the root, which renders `analysis/*.qmd` through the root `_quarto.yml`. The RStudio Render button can rebuild only the HTML, so after using it, check that the DOCX is still there.

## Extraction rules

- Keep every value and name exactly as printed in the report. Never correct a value. Document known problems instead.
- Numeric tables (9 to 13, Annexure II) are read with `read_numeric_table()` and `value_tokens()` from `pdftotext -layout`. Each number is placed by its column position, so an empty cell stays `NA` instead of shifting the values after it. The column positions are computed per page and per table, because two tables can share a page with different column positions.
- Text tables (1 to 8) are read with `read_words()` from `pdftotext -bbox`, because their cells wrap over several lines and two cells can be separated by a single space.
- Take `state` from `plant-names.csv`, not from the group rows of a table. Table 13 has no "Uttar Pradesh" group row.
- Each script stops with an error when its counts differ from the printed table. Keep these checks when you change a script.
- After any change to an extraction script, compare all values with an independent parse of the PDF text, and check that the tests still pass.

## Known problems in the report

Keep these values as printed. Tests and documentation refer to them.

- Table 9 has no BOD removal value for Nalgonda, while Graph 5 shows 97.2%.
- Amethi shows 48.3 mg/L BOD and 1.2% removal in Table 9, while Graph 4 and Annexure II give 30.1 mg/L. The plant was sampled only once.
- Dhenkanal shows 30.6 mg/L BOD in Table 9, while Annexure II and the Odisha chapter give 14.0 mg/L.
- Table 9 does not explain the asterisk on Modinagar. Table 5 lists it as a hyper core (lamella) pilot plant.
- Annexure II prints the inlet pH of Thirumangalam as 280.6.
- Table 11 differs from the FS rows of Annexure II for several plants, e.g. Nanakramguda's pH and Uppal's COD.
- The report's text says six FSTPs fail the 30 mg/L BOD standard, but Table 9 gives eight. `analysis/bod-compliance.qmd` explains the difference.

## Naming

- Files use lowercase with dashes, and scripts have a two-digit prefix.
- Exceptions forced by R and washr: dataset objects and their files use underscores (e.g. `fstp_performance.rda`), and the package name is `fstpindia`.
